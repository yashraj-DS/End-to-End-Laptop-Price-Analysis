# End-to-End Laptop Price Analysis

An end-to-end data analytics project focused on understanding laptop pricing through data cleaning, exploratory data analysis (EDA), dashboarding, and machine learning.

## Project Overview

This project uses a laptop price dataset containing over 1,300 laptop listings collected from an e-commerce platform. The dataset includes information such as laptop brand, processor, RAM, storage, display specifications, operating system, weight, and price.

The goal is to transform raw, uncleaned data into meaningful insights and predictive models through a complete analytics workflow.
